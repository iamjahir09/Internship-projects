# Nationality Detection

This project estimates nationality-related attributes from a face image using a trained classifier model.

## What is included
- dataset/: face dataset used for training
- model/: trained model files
- src/gui.py: user interface
- src/predictor.py: prediction logic

## Run
```bash
python src/gui.py
```

## Notes
- This project is intended for academic and demo purposes.
- Model accuracy depends on dataset quality and training setup.

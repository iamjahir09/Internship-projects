# Animal Detection

This project detects animals from images or live camera input using a trained deep learning model.

## What is included
- dataset/: labeled animal images
- model/: trained model and TensorFlow files
- src/gui.py: graphical interface for detection

## Run
```bash
python src/gui.py
```

## Notes
- This project is designed for quick animal recognition.
- Use the app to upload an image or run live detection.

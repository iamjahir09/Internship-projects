# Sign Language Detection

This project recognizes sign language gestures from images using a trained deep learning model.

## What is included
- dataset/: ASL training and test images
- model/: saved model and label files
- src/gui1.py: graphical interface

## Run
```bash
python src/gui1.py
```

## Notes
- The app can be used to classify sign language alphabet gestures.
- The dataset contains ASL image samples for model training.
